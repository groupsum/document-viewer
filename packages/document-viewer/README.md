# @groupsum/document-viewer

React document viewer component package for Groupsum applications.

## Install

```bash
pnpm add @groupsum/document-viewer
```

## Use

```tsx
import { DocumentViewer } from '@groupsum/document-viewer';
import '@groupsum/document-viewer/style.css';
```

## Scripts

- `pnpm run test`
- `pnpm run typecheck`
- `pnpm run build`
