# @groupsum/pdf-viewer

React PDF viewer component package for Groupsum applications.

## Install

```bash
pnpm add @groupsum/pdf-viewer
```

## Use

```tsx
import { PDFViewer } from '@groupsum/pdf-viewer';
import '@groupsum/pdf-viewer/style.css';
```

## Scripts

- `pnpm run test`
- `pnpm run typecheck`
- `pnpm run build`
